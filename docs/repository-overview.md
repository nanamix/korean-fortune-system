# Repository Overview

## 프로젝트 목적
`nanamix/korean-fortune-system`는 한국형 운세 도메인(사주팔자, 오늘의 운세, 토정비결, 별자리 운세)을 API로 제공하는 백엔드 중심 프로젝트입니다. 전통 운세 계산 결과를 서비스화하고, 필요 시 AI 해석을 결합해 사용자에게 전달하는 것을 목표로 합니다.

## 핵심 기능 요약
- 사주팔자 계산(사주 4주, 오행/해석 정보 포함)
- 오늘의 운세 계산
- 토정비결(144괘) 계산
- 별자리 운세 제공
- 운세 결과 알림 발송(예: 이메일/메신저 연계)
- AI 기반 해석/보강(비활성 또는 폴백 가능한 구조)

## 기술 스택 (저장소 기준 추정)
- **언어 구성**: Java 중심 + HTML 리소스 + 기타 설정/스크립트
- **백엔드 프레임워크**: Spring Boot 기반 REST API
- **빌드 도구**: Gradle
- **데이터 계층**: JPA 기반 영속성 사용
- **운세 계산 라이브러리**: 음양력/간지 계산 라이브러리 활용
- **AI 연동 방식**: OpenAI 호환 인터페이스 기반 확장 구조

## 저장소 메타데이터 요약
- **저장소**: `nanamix/korean-fortune-system`
- **공개 여부**: Public
- **기본 브랜치**: `master`
- **주요 포지셔닝**: 한국형 운세 API + AI 보조 해석

## 아키텍처/프로젝트 성격 해석
이 프로젝트는 단순 콘텐츠 사이트가 아니라, 운세 계산 로직을 서비스 계층으로 캡슐화하고 HTTP API로 노출하는 **도메인 특화 애플리케이션 서버**에 가깝습니다. 또한 AI 기능을 핵심 계산 로직과 분리해 선택적으로 결합할 수 있도록 구성되어, 전통 계산 정확성과 확장성을 동시에 추구하는 구조로 해석할 수 있습니다.
