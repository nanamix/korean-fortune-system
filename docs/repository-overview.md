# Repository Overview

## 개요
`nanamix/korean-fortune-system`는 한국형 운세 서비스를 제공하는 Java 기반 API 프로젝트입니다. 저장소 설명에 따르면 운세, 사주, 토정비결, 별자리 운세를 다루며, AI 기능과의 결합도 염두에 둔 구조로 보입니다.

## 핵심 특징
- 운세/사주/토정비결/별자리 운세를 제공하는 도메인 특화 서비스
- Java 중심의 백엔드 구현
- HTML 리소스를 포함한 웹 UI 또는 템플릿 제공 가능성
- AI 연동을 고려한 확장형 구조

## 기술 스택 추정
- **Java (76.1%)**: 핵심 비즈니스 로직, API, 서비스 계층
- **HTML (21.8%)**: 화면 출력 또는 템플릿
- **Other (2.1%)**: 설정 파일, 리소스, 스크립트 등
